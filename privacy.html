개인정보처리방침

Effective date: 2026-10-09 · API Client: Facts & Context Publisher · English

Facts & Context Publisher는 YouTube API Services를 사용합니다. 사실과 맥락 채널 운영자가 자신의 채널에 자체 제작 콘텐츠를 게시하기 위한 내부 도구이며, 일반 사용자에게 제공하지 않습니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하게 됩니다.

1. 이용 목적

운영자가 명시적으로 승인한 영상과 메타데이터를 운영자 소유 채널에 업로드하고, 업로드 대상 채널이 올바른지 확인하기 위해 사용됩니다.

2. 사용하는 권한

  • youtube.upload — 운영자가 승인한 영상과 메타데이터를 업로드하고(videos.insert), 맞춤 썸네일을 설정합니다(thumbnails.set).
  • youtube.readonly — 인증된 채널의 채널명과 채널 ID를 읽어 대상 채널을 확인하고(channels.list, mine=true), 방금 업로드한 영상의 공개 상태를 확인합니다(videos.list).

기존 영상의 수정·삭제, 댓글, 분석 데이터, 다른 사용자나 다른 채널의 데이터에는 접근하지 않습니다.

3. 접근·저장하는 YouTube API 데이터

YouTube API Services에서 받아 저장하는 정보는 다음뿐입니다.

  • 인증된 채널의 채널명과 채널 ID
  • 이 도구로 업로드한 영상의 영상 ID, 제목, 공개 상태, 예약 게시 시각, 업로드 상태

그 밖에 OAuth 인증에 필요한 액세스 토큰과 갱신 토큰을 저장합니다(5·6절).

다음은 YouTube API 데이터가 아니라 운영자 자신의 작업 기록입니다: 업로드 일시, 로컬 파일 이름·크기·MD5 체크섬, 운영자가 보낸 제목과 공개 설정, 운영자 승인 코드. 운영자가 업로드하는 영상 파일과 메타데이터도 운영자가 직접 만든 것입니다.

4. 정보의 사용과 공유

위 정보는 업로드 대상 채널 확인, 업로드 실행, 업로드 결과 확인, 같은 파일의 중복 업로드 방지에만 사용합니다.

  • YouTube API Services로 얻은 정보를 판매하지 않습니다.
  • 광고, 프로파일링, 분석에 사용하지 않습니다.
  • 인공지능·머신러닝 모델의 학습에 사용하지 않습니다.
  • 법률상 요구되는 경우를 제외하고 제3자에게 제공하지 않습니다.
  • 이 도구와 이 웹사이트는 제3자가 광고 등 콘텐츠를 게재하도록 허용하지 않습니다.

5. 기기에 저장하는 정보와 보안

이 도구는 운영자의 컴퓨터(기기)에 다음 정보를 저장합니다.

  • OAuth 토큰: 소스 코드 저장소 밖의 설정 폴더에 운영자 계정만 읽을 수 있는 권한(폴더 700, 파일 600)으로 저장합니다. 화면이나 기록 파일에 출력하지 않습니다.
  • 업로드 기록: 3절의 작업 기록과 YouTube API 데이터. 기록하기 전에 토큰·secret이 들어 있지 않은지 자동으로 검사하며, 토큰이나 클라이언트 secret은 기록하지 않습니다.

이 공개 웹사이트에는 OAuth 자격 증명이나 토큰을 저장하거나 게시하지 않으며, 쿠키나 추적 기술을 사용하지 않습니다.

6. 보관 기간

  • OAuth 토큰: 운영자가 권한을 철회하거나 토큰을 교체할 때까지 보관합니다. 교체·철회할 때는 Google에서 폐기한 뒤 삭제합니다.
  • YouTube API 데이터(3절): 받은 날부터 30일이 지나면 자동으로 삭제합니다. 갱신해서 보관 기간을 늘리지 않습니다. 이 정리는 도구를 실행할 때마다, 그리고 하루 한 번 예약 작업으로 실행됩니다.
  • 작업 기록(YouTube API 데이터 아님): 같은 파일의 중복 업로드를 막기 위해 보관하며, 운영자가 언제든 삭제할 수 있습니다.

7. 권한 철회와 데이터 삭제

언제든지 Google 보안 설정 페이지에서 이 API Client의 접근 권한을 철회할 수 있습니다.

  • Google 보안 설정 — 계정에 액세스할 수 있는 앱

도구는 실행할 때마다, 그리고 하루 한 번 승인이 유효한지 확인합니다. 권한이 철회된 것을 확인하면 로컬 OAuth 토큰과 YouTube API 데이터를 바로 삭제하며, 늦어도 철회 후 30일 안에 삭제를 마칩니다.

삭제 요청: 아래 이메일로 요청하면 저장된 YouTube API 데이터를 7일 안에 삭제하고 결과를 회신합니다.

Privacy Policy — Facts & Context Publisher

Effective date: 2026-10-09

Facts & Context Publisher uses YouTube API Services. It is an internal, single-operator desktop tool used by the operator of the YouTube channel 사실과 맥락 (Facts & Context) to publish operator-approved original content to the operator's own channel. It is not offered to the public. By using the tool, the operator agrees to be bound by the YouTube Terms of Service.

Scopes and use

  • youtube.upload — uploads operator-approved videos and metadata (videos.insert) and sets custom thumbnails (thumbnails.set).
  • youtube.readonly — reads the authorized channel's title and ID to verify the destination channel (channels.list, mine=true) and checks the privacy status of a video just uploaded (videos.list).

The tool does not edit or delete existing videos, and does not access comments, analytics, or any other user's or channel's data.

YouTube API Data accessed and stored

The only information obtained from YouTube API Services and stored is:

  • the authorized channel's title and channel ID
  • for videos uploaded by the tool: video ID, title, privacy status, scheduled publish time, and upload status

The tool also stores the OAuth access and refresh tokens. The following are the operator's own work records, not YouTube API Data: upload time, local file name, size and MD5 checksum, the title and privacy settings the operator sent, and the operator's approval code.

How information is used and shared

This information is used only to verify the destination channel, perform the upload, verify the result, and prevent duplicate uploads of the same file. We do not sell it, use it for advertising, profiling or analytics, use it to train artificial intelligence or machine learning models, or share it with third parties except where required by law. Neither the tool nor this website allows third parties to serve content, including advertisements.

Information stored on devices

The tool stores on the operator's computer: (1) OAuth tokens, in a configuration folder outside the source repository, readable only by the operator's account (folder 700, files 600), never printed or logged; and (2) an upload log containing the work records and the YouTube API Data listed above. Every entry is automatically checked before it is written, and the log never contains tokens or client secrets. This website stores no credentials and uses no cookies or tracking technologies.

Retention

  • OAuth tokens are kept until the operator revokes or rotates them; they are then revoked with Google and deleted.
  • YouTube API Data is deleted automatically 30 days after it was retrieved. It is not refreshed to extend retention. This clean-up runs every time the tool runs and once a day as a scheduled job.
  • Work records (not YouTube API Data) are kept to prevent duplicate uploads and can be deleted by the operator at any time.

Revoking access and deleting data

You can revoke this API Client's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. The tool checks that its authorization is still valid every time it runs and once a day. When revocation is detected, the local OAuth tokens and all stored YouTube API Data are deleted immediately, and in any case within 30 days of revocation.

Deletion requests: email the address below and stored YouTube API Data will be deleted within 7 days, with a reply confirming the deletion.
